AI Personal Study Assistant 🤖

About the Project

The AI Personal Study Assistant is an AI-powered learning chatbot designed to help first-year B.Tech Computer Science students learn Python programming in a simple and interactive way.

Objectives

- Help students understand Python concepts easily.
- Provide instant answers to students’ questions.
- Generate simple Python code examples and explanations.
- Make learning more interactive and enjoyable.
- Help students practise and revise lessons.

Technologies and Concepts

- Generative AI
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- Embeddings
- Python Programming
- AI Chatbots and Web Development

Learning Experience

As part of the one-week Generative AI classes conducted by IBM, I learned about LLMs, RAG, embeddings, and how AI works in real-world applications. I also enjoyed creating my own website and chatbot and applying what I learned in a practical way.

Conclusion

This project was a wonderful learning experience that helped me explore the exciting world of Generative AI. I am grateful to IBM for this opportunity and happy to have gained new knowledge, skills, and confidence in using AI to create useful learning tools.
